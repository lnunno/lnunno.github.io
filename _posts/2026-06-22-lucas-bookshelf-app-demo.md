[Open Lucas' Bookshelf](/apps/books/)

I'm particularly proud of this one and I've found myself using it frequently as a better way to interact with my Goodreads data and also my Kindle highlights. Instead of being on a pretty slow and antiquated website I have all my reading history on one web page that I can sort, filter, and search quickly.

The Trends page visualization I've found particularly helpful as it will show my reading history on a chart that also respects all the filters from the Read page book grid so it really emphasizes the differences in temporal + rating + highlights.

An app I built that visualizes books read, want to read with a number of different filters. Has a book page view that shows all highlights, rating, genre and subgenres, taste role.

Shows reading trends in two different charts with different visualizations to scale them based on number of highlights and show the time spent reading, as well as monthly stats as a heatmap with different selectable color keys.
